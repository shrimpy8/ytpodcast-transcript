# AI Tools & Workflows

## Replet Design Mode with Gemini 3
- **Primary use**: Building front-end websites and apps without writing code
- **Key feature**: Can generate AI videos as backgrounds and integrate them automatically into designs
- **Important distinction**: Design Mode creates front-end code only; can be converted to Build Mode for backend functionality
- **Publishing**: One-click website publishing directly from the platform
- **Mobile capability**: Can do "vibe coding" on mobile app while on the go - paste images and give prompts

## Workflow: Creating Websites with AI-Generated Content

1. Work with AI (Claude mentioned as example) to create a detailed spec and prompt
2. Break down complex projects into milestones (example given: three different milestones)
3. Ask AI to "edit everything that we talked about into a prompt that I can paste into AI to generate the result"
4. Copy the finalized prompt into Replet Design Mode (switch from "build" to "design" mode)
5. Remove placeholder instructions (e.g., "video placeholder stuff") and add specific requests (e.g., "generate AI videos as backgrounds")
6. Let Replet generate the website
7. Iterate with back-and-forth conversations to refine details
8. Click "publish" to make the website live

## Key Tips
- **Be specific about visual elements**: Describe the exact videos, animations, or aesthetics you want
- **Reference existing designs**: "Let's mimic these two popular audio companies" - providing style references helps
- **Don't be afraid to iterate**: The host emphasizes going "back and forth with AI to make it work"
- **Use AI to help create prompts**: Work with AI first to develop the specification and prompt rather than starting from scratch
