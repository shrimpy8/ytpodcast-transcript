## Full Description

A modern Next.js web application for extracting, processing, and exporting YouTube podcast transcripts. Built with TypeScript, Tailwind CSS, and shadcn/ui components.

### Key Features
- 🎬 Extract transcripts from YouTube videos using yt-dlp
- 🎤 Automatic speaker detection (Host/Guest)
- 🔄 Intelligent deduplication of repetitive content
- 📤 Multiple export formats (TXT, JSON, SRT, VTT)
- 🤖 AI-powered summaries from multiple LLM providers (Anthropic, Google Gemini, Perplexity)
- 📺 Channel and playlist video browsing
- 🔍 Interactive transcript viewer with search
- ⚡ Performance optimized with caching and memoization
- ♿ WCAG 2.1 AA compliant accessibility
- 🌙 Dark mode support

### Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript 5+
- **Styling**: Tailwind CSS 4+
- **UI Components**: shadcn/ui
- **Transcript Extraction**: yt-dlp
- **AI Integration**: Anthropic Claude, Google Gemini, Perplexity

### Perfect For
- Content creators creating blog posts from podcasts
- Researchers analyzing podcast content
- Podcast enthusiasts creating readable transcripts
- Developers building transcript processing tools
