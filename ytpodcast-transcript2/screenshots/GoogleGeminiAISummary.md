# AI Tools & Workflows

## Replet Design Mode & Gemini 3
*   **How it's used:** Users switch from "build to design mode" in Replet, paste a detailed prompt, and the AI generates a website or app.
*   **Key tip:** When generating websites with full-screen videos, explicitly describe the desired AI videos in the prompt.
*   **Publishing:** Websites and apps can be published "in a single shot" by clicking a "publish" button.
*   **Limitations:** The AI agent builder interface generated is front-end code only; backend functionality, databases, and full interactivity (like a fully functional poker game or complex interactive maps) may require further development in Replet's build mode.

## Workflow: Building a Travel Catalog Website with AI Videos
1.  **Generate initial prompt:** Work with AI (e.g., **Claude**) to create a prompt describing the desired website (e.g., "stunning travel catalog website to showcase my top five countries with full screen videos").
2.  **Describe video shots:** Specifically describe the video content desired for each section (e.g., "generate AI videos as backgrounds for each country screen based on the descriptions below").
3.  **Paste into Replet Design Mode:** Copy the refined prompt into Replet's design mode.
4.  **Iterate and refine:** Engage in "back and forth" conversations with AI to edit copy, link to external content (e.g., favorite restaurants), and adjust scope if initial ambitions are too complex (e.g., interactive maps).
5.  **Publish:** Click publish to make the website live.

## Workflow: Building a Retro Personal Operating System
1.  **Plan with AI:** Ask AI to write a specification broken down into milestones to avoid building "too much at once."
2.  **Generate prompt:** Ask AI to consolidate the spec into a prompt for generation.
3.  **Generate base OS:** Use the AI-generated prompt in **Replet Design Mode** to create the initial operating system interface.
4.  **Update copy:** Ask AI to perform copy updates (e.g., adding experience from LinkedIn, links to newsletters).
5.  **Integrate images/content:** Search online for relevant images (e.g., screenshots of old games), paste them into the mobile app, and prompt AI to create structured content (e.g., a "memories folder" with nostalgic photos in a gallery).

# Technology Trends & Industry Insights

*   **Rise of "Vibe Coding":** The ability to build "beautiful websites and operating systems while you're actually on the go" using AI tools and even mobile devices, without writing code.
*   **Democratization of Design & Development:** AI tools like **Replet Design Mode** and **Gemini 3** enable anyone to generate "professional looking websites" in minutes, a task that "would have cost thousands of dollars" and required hiring a designer previously.
*   **Focus on Front-End Prototyping:** AI-generated interfaces, while often front-end code only, are valuable for rapid prototyping and validating ideas with stakeholders before investing in full backend development.
*   **AI as a Collaborative Partner:** The workflow emphasizes "working with AI" to plan, spec, generate prompts, and refine content, positioning AI as an interactive assistant rather than just a code generator.
